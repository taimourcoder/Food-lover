html and css and js 👩🏻‍💻
1. HTML (HyperText Markup Language):
What it does: Structures the content of a webpage.
Think of it as: The skeleton of a website.

2. CSS (Cascading Style Sheets):
What it does: Styles the HTML elements—colors, layout, fonts, etc.
Think of it as: The skin and clothing of the website (makes it look good).

3. JavaScript (JS):
What it does: Adds interactivity and behavior to the webpage (buttons that work, sliders, form validation, etc.).
Think of it as: The muscles and brain of the website.


How They Work Together:
Imagine building a car:

🍟HTML is the frame and parts.

🍟CSS is the paint, polish, and style.

🍟JS is the engine and electronics.


On a website:
You write HTML to put text and buttons.
You use CSS to make it look nice.
You use JavaScript to make things move or respond to clicks.
